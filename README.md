# ELISA Railways special interest group
This is the GitHub repository of the Railways special interest group (SIG) of the ELISA project. This repo is used to collect the meetings minutes of our monthly calls. It will also serve as a central reference point for all the projects that are being undertaken by the SIG.

## Issues
Please head over to the [Issues](https://github.com/elisa-tech/railways/issues) to check out currently active discussions within the group. This is also where you can find inspiration on how to participate. 

## Meetings 
We currently meet every 3rd Tuesday a month at 1 pm UTC. You can find [more information on upcoming meetings here](https://lists.elisa.tech/g/railways).
